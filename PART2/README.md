# Part 2 – FP8 Systolic Matrix Multiplication

## Overview

Part 2 integrates the FP8 arithmetic units developed in Part 1 into the provided 4×4 systolic matrix multiplier.

The original integer multiply-accumulate operation is replaced with an FP8 MAC using the FP8 multiplier and FP8 adder:

C_new = C_old + (A × B)

Exception flags generated by the FP8 multiplier and adder are propagated through the systolic matrix multiplier.

The baseline integer design and the modified FP8 design are also synthesized for area and timing comparison.

## FP8 Matrix Multiplication Simulation

Go to the FP8 matrix multiplication simulation directory:

```bash
cd PART2/fp8_matmul/sim
```

Clean previously generated files:

```bash
make clean
```

Compile the FP8 matrix multiplication design, RAM wrapper, and testbench and generate the Verdi KDB database:

```bash
make compile_verdi
```

Run the simulation:

```bash
./simv
```

The testbench automatically executes two test cases:

1. Normal FP8 matrix multiplication with no exception.
2. FP8 matrix multiplication containing positive infinity to verify exception propagation.

The simulation prints PASS/FAIL results and generates the FSDB waveform database.

Open the waveform in Verdi:

```bash
make waves_verdi
```

The waveform can be used to observe:

- Input matrix reads from RAM
- `start` assertion
- `done` assertion
- FP8 exception flags
- Output matrix writes to RAM

## INT8 Baseline Synthesis

The baseline integer design is used for synthesis comparison with the FP8 implementation.

Go to the baseline synthesis directory:

```bash
cd PART2/baseline/synth
```

Clean previous synthesis results:

```bash
make clean
```

Run synthesis:

```bash
make synth
```

The baseline synthesis uses `matmul_ori.v` with `matmul_4x4_systolic` as the top-level module.

The following reports are generated:

- `area.rep`
- `timing.rep`
- `cell.rep`
- `power.rep`

## FP8 Matrix Multiplication Synthesis

Go to the FP8 synthesis directory:

```bash
cd PART2/fp8_matmul/synth
```

Clean previous synthesis results:

```bash
make clean
```

Run synthesis:

```bash
make synth
```

The FP8 synthesis uses:

- `matmul.sv`
- `fp8_adder.sv`
- `fp8_multiplier.sv`

with `matmul_4x4_systolic` as the top-level module.

The following reports are generated:

- `area.rep`
- `timing.rep`
- `cell.rep`
- `power.rep`

The generated synthesis reports can be used to compare the area and timing performance of the baseline integer and FP8 implementations.
